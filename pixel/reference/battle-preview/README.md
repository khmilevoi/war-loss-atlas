# Исходный боевой предпросмотр

Побайтовая копия файлов, обследованных в независимой проверке. Хеши, размеры и геометрия атласов записаны в `manifest.json`. Папка нужна для воспроизводимости и находится вне `public/` и `src/`.

Манифест связывает снимок с исходным каталогом. SHA-256 определяет конкретные файлы. Git ref старого атласа относится к рабочей копии на момент браузерной проверки. Происхождение уже собранного SSR-каталога отдельно не подтверждено.

Press Start 2P встроен в CSS, текст SIL OFL 1.1 приложен. Все семь листов PNG прослежены до генераций этого проекта. Для фонового WebP подтверждены рабочий источник и содержимое. Происхождение фона для публикации отдельно не проверялось. Контрольные изображения предпросмотра хранятся отдельно от рабочих спрайтов. [Опись происхождения](../../../../docs/superpowers/plans/2026-11-07-pixel-war-atlas-release.md#происхождение-спрайтов)

Из канонического каталога можно запустить копию через `node web-atlas/pixel/reference/battle-preview/atlas-grounded-preview.mjs`. Нужен собранный действующий атлас с клиентским HTML, серверным входом и ровно одним `entry-server-*.js` в `web-atlas/dist/server/assets/`.
