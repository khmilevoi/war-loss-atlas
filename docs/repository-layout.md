# Устройство общего репозитория

Атлас и воспроизводимая часть исследования находятся в одном репозитории. Все команды запускаются из его корня.

| Где | Что лежит |
| --- | --- |
| `src/`, `public/`, `data/` | Атлас, его источники и разрешённые наборы данных |
| `starter/` | Первый расчёт на Python, независимая сверка на SQL и контрольная таблица |
| `research/` | Методика, реестр наборов и проверенные результаты |
| `full_research`, `output`, `stage2`–`stage4` | Локальная история исследования, оригиналы и архивы |

## Как добавить материал

В своей ветке опишите, что изменилось и на какую версию источника опирается результат. Для нового входного файла укажите издателя, версию, условия доступа, место хранения и SHA-256. Исходники храните побайтно. Исправления и преобразования оформляйте отдельно, чтобы сохранить связь с исходной записью.

Файл включается в общий Git после проверки условий распространения. Если набор каждый получает у издателя, в Git достаточно оставить запись в реестре. Локальный архив содержит материалы с разными условиями доступа и остаётся по прежним путям. [Реестр наборов](../research/sources.csv)

`npm run public:check` проверяет доступные Git файлы рабочей копии, сборку, индекс и историю текущей ветки. Для сборки Docker действует собственный список файлов. При добавлении нового общего материала обновите точный список допустимых путей в проверке релиза вместе с атрибуцией.

## Подключение существующей папки исследования

1. Проверьте сборку атласа и запуск анализа на чистом клоне общей ветки.
2. Зафиксируйте обе локальные истории Git и сохраните незакоммиченные правки вложенного атласа. Проверьте резервные ссылки или копии до переключения.
3. Сохраните прежний исследовательский README под именем `RESEARCH_README.md` в том же корне, чтобы его относительные ссылки продолжали работать. Сверьте контрольные суммы локальных источников и проверьте пересечения путей с общей веткой.
4. Подключите текущую корневую папку к общей истории Git. После переключения повторите аудит релиза, расчёт и проверку исходников. Решение о судьбе вложенной копии принимайте после этих проверок.
