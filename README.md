# Атлас войн и исследование организованного насилия

- **Атлас** — двуязычная карта с историческими справками, оценками потерь и пиксельными сценами. [Русская версия](https://wars.iiskelo.com/ru/) · [English version](https://wars.iiskelo.com/en/).
- **Исследование** — данные UCDP, методика, контрольные таблицы и примеры анализа. [Путеводитель по исследованию](research/README.md) · [Первый расчёт](starter/README.md).
- **Структура проекта** — правила работы с общим Git и локальным архивом. [Устройство репозитория](docs/repository-layout.md).

## Запуск и проверка

Нужны Node.js 24 и npm. Выполните команды из корня репозитория.

```sh
npm ci
npm run dev
```

Откройте `/ru/` или `/en/` по адресу, который выведет Vite.

```sh
npm test
npm run typecheck
npm run build
npm run public:check
npm run test:browser
```

Исходники находятся в `src/`, статическая сборка — в `dist/`. Браузерные тесты используют Google Chrome и проверяют эту сборку.

## Данные

Общий каталог содержит 1650 строк «конфликт–год» UCDP 26.1 за 1989–2025 годы, 202 конфликта и четыре исторические оценки с отдельными определениями. Доступные оценки относятся к периодам и типам потерь, указанным в карточках. Пропуск отличается от нулевой оценки.

`npm run data:import` воспроизводит каталог из включённых CSV и геоданных. `npm run data:check` сверяет данные и содержимое рабочей копии. `npm run public:check` также проверяет Git-индекс и историю текущей ветки. ## Развёртывание

`docker compose -f docker-compose.pixel.yml config` проверяет конфигурацию. Статический сервер Nginx слушает порт 8080, `/health` возвращает 200. Опубликованное окружение RPi — `war-atlas--pixel` (`--env pixel`). [Развёртывание](docs/deployment.md).
