# Атлас потерь

Интерактивный каталог человеческих потерь: полный ряд UCDP 26.1 за 1989–2025 годы и четыре отдельные исторические карточки. Это не общий итог всех войн и не рейтинг стран или культур.

## Запуск и воспроизведение

Нужны Node.js 24 и npm; версии пакетов закреплены в `package-lock.json`.

```sh
npm ci
npm run data:import
npm run data:check
npm test
npm run typecheck
npm run build
npm run public:check
npm start
```

Откройте `http://localhost:3000/` или `/data`; `/health` возвращает 200. Для разработки: `npm run dev` (порт задаётся переменной `PORT`). Полный браузерный набор требует установленного Google Chrome и Vite development server на 4173: `PORT=4173 npm run dev`, затем `npm run test:browser`. В PowerShell перед запуском сервера: `$env:PORT='4173'`. Для production используется `ATLAS_TEST_URL` (PowerShell: `$env:ATLAS_TEST_URL='http://localhost:3000'`) и отдельная проверенная выборка из [протокола](docs/verification.md); три canvas-теста с инструментированием исходного модуля выполняются только в development.

Импорт использует включённый разрешённый CSV и закреплённые геоданные, сетевой запрос к архиву не требуется. Его SHA256: `b34ecb57f1fc0e73d4bfd7b080212da429af3135a8d360b1c902e45506f81147`. [Манифест](data/manifest.json) сохраняет версии и контрольные суммы. `public:check` проверяет исходное дерево, bundle, индекс и все достижимые версии файлов в Git; `.dockerignore` допускает в сборку только необходимые входные файлы.

## Что означают числа

- UCDP: 1650 уникальных строк «конфликт–год», 202 конфликта, 25 исходных полей. Суммы best / low / high: 2 566 047 / 2 410 880 / 3 330 850. Это связанные с боями смерти по определению источника; low/high не доверительный интервал и не поправка на неполноту мира.
- Период выбирает конфликты по первому наблюдаемому году, обе границы включены. Сумма и CSV сохраняют все доступные годы выбранного конфликта. Первый год наблюдения не обязательно начало войны; пропуск не равен нулю.
- Четыре исторические карточки имеют разные определения: Первая мировая — около 16 млн; Вторая мировая — более 65 млн; Гражданская война в США — не менее 750 тыс.; Корея — около 2 млн гражданских двух Корей. Их нельзя складывать с UCDP или между собой. Четыре публикации принадлежат трём организациям: NARA, NAM и NPS.
- 94 конфликта имеют условную навигационную метку, 108 — без координат. Общая метка раскрывает каждый ID отдельно. Размер точки не показывает число погибших; страновые итоги не рассчитываются. Исторические якоря символические.

[Атрибуция UCDP, CC BY 4.0](public/licenses/ATTRIBUTION.md), [условия Natural Earth](public/licenses/NATURAL-EARTH.txt), [источники исторических фактов и оговорки](public/licenses/HISTORICAL-FACTS.md). Исторические записи — собственные краткие парафразы, не копии музейных текстов или изображений. Ограниченные данные COW, исследовательский архив и секреты в поставку не входят.

## Развёртывание

`docker compose config` проверяет service `web`; образ слушает `0.0.0.0:3000`, Compose использует `expose`, фиксированного host port нет. Runtime содержит compiled SSR, клиентские файлы и production-зависимости; работает от пользователя `node`.

```sh
docker compose build
rpi deploy --server home
```

`rpi.toml`: проект `war-atlas`, private repository `git@github.com:khmilevoi/war-loss-atlas.git`, ветка `main`, hostname `war-atlas.iiskelo.com`, проверка `/health` → 200. Pi получает read-only deploy key штатным механизмом rpi; ключи и токены в приложение не копируются. Текущее состояние выпуска и доказательства: [проверки](docs/verification.md), [аудит данных](docs/data-audit.md), [размещение](docs/deployment.md).
